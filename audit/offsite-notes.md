## llms-full.txt regeneration dependency

- `llms-full.txt` is generated by `scripts/generate-llms-full.py` from the
  live text of every page it lists. It does not read `site-config.json`;
  it only copies whatever text is already on each page.
- The "NN Google reviews" trust line is one such piece of copied text, and
  it is materialized 53 times across the site (once per marked page).
  Whenever `update-review-count.py` is run and changes the review count or
  rating, `scripts/generate-llms-full.py --apply` must be re-run afterward
  so `llms-full.txt` reflects the same numbers as the live pages. This is a
  manual, sequential dependency: regenerate the count first, then
  regenerate llms-full.txt.
